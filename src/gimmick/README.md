
# Gimmick Puppet

这是一个本地化devops实践辅助工具, 用来帮你在离线ci/cd环境下也能获得较好地自动化能力.  

## Guidences

服务生成方法的指导手册, 一些配置比较复杂/定制比较灵活的过程没有被做成自动化脚本, 而是以建议的方式放在这里.  
这里的代码也可以实践, 但执行前需仔细阅读说明.

## Services

自动化处理方法放在这里并可执行, 通过定制脚本实现自动化管理.

## Ignore Folers

第一次启动执行`init.sh`创建默认路径目录.  
这些目录也可以自定义, 通过修改`conf.rb`中的路径关联到项目外的工作目录.

> **.config** 
> 存放项目配置文件
> 这个目录有一个最重要的配置文件(path.yaml),用来指定其他各项脚本使用的配置路径信息
> **.datahouse** 
> 存放数据文件, 可以是自动生成的,也可以是手动添加的,记得备份
> **.script** 
> 存放脚本文件, 
> **.tmp** 
> 存放一些中间数据
