# lightmare-exlink

a document tool for sdn

## 上传项目

这些项目将被上传到[比翼平台仓库](gitlab.ctbiyi.com)

1. [Lightmare=Exlink](https://gitlab.ctbiyi.com/Frampt/lightmare-exlink.git)

研究YANG、NETCONF、OpenAPI等转化方法的项目,目标是针对不同YANG模型编写业务流实现控制

2. [Qliphoth](https://gitlab.ctbiyi.com/Frampt/qliphoth.git)

一些工具的定义,这里实现scout做一个词法分析器+语法分析器,至少做到LALR(1)

3. [Gimmick](https://gitlab.ctbiyi.com/Frampt/gimmick.git)

本地化的devops工具,将项目为项目添加一些辅助配置和脚本
